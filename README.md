# Fyminal

A minimal personal iPhone SSH terminal for working on a Mac over an existing Tailscale connection.

Connect, use the Mac's shell and AI command-line tools, and resume surviving work through tmux. WezTerm remains the local Mac terminal. No Fyminal backend or AI integration is required.
